# Creator outfit artwork

These images depict confirmed Fortnite Icon Series outfits and are used on this free, unofficial fan website under Epic Games' Fan Content Policy.

The cosmetic image files were retrieved from the public Fortnite-API cosmetic catalog on October 18, 2026. Fortnite-API is an unofficial data service. Icon Series status was checked separately against official Fortnite pages:

- `ali-a-icon.png` — [official Ali-A announcement](https://www.fortnite.com/news/ali-a-is-unleashed-in-the-fortnite-icon-series)
- `typical-gamer-icon.png` — [official Typical Gamer Icon Cup page](https://www.fortnite.com/competitive/events/S40_TypicalGamerCup/)
- `loserfruit-icon.png` — [official Loserfruit announcement](https://www.fortnite.com/news/loserfruit-joins-the-fortnite-icon-series)
- `lachlan-icon.png` — [official Lachlan announcement](https://www.fortnite.com/news/lachlan-joins-the-fortnite-icon-series)

The following transparent portraits were created from images supplied by the site owner using the built-in ImageGen background-extraction workflow. Only the backgrounds and unrelated edge artifacts were removed:

- `littlest-snail-starflare.png` — Starflare, featured in [LittlestSnail's official Locker Bundle](https://www.fortnite.com/item-shop/offers/littlestsnails-locker-bundle-18aa761b?itemNotAvailable=true)
- `happyhappygal-miss-bunny-penny.png` — Miss Bunny Penny, featured in HappyHappyGal's Locker Bundle as documented by Fortnite's [Sun Sprout listing](https://www.fortnite.com/item-shop/back-bling/sun-sprout-39edfd30?itemNotAvailable=true)
- `sawahh-rippley.png` — Rippley portrait supplied by the site owner for Sawahh's creator card; the checkerboard background was removed with the built-in ImageGen background-extraction workflow.
